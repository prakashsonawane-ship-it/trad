Why 3:00 PM, Not 2:45 PM
Institutional money remains active until the final 15 minutes of trading. FII and DII desks often take or close large positions between 2:45–3:00 PM, creating the final directional move of the session. Option premiums do collapse rapidly after 2:45 PM, but if you're already in a profitable position, riding it to 3:00 PM with a trailing stop captures this institutional close. New entries: cut off at 2:15 PM. Existing positions: manage actively until 3:00 PM hard close.
3 — Current Affairs Intelligence Layer
The agent must know what's happening in the world before it reasons about any trade. A technically perfect setup gets destroyed by an unexpected RBI announcement or a geopolitical shock. This is a new layer that runs before the session starts and is refreshed at key intervals.

Why Current Affairs Changes Everything
On days with major macro events — RBI policy, US Fed minutes, CPI data, budget announcements, geopolitical escalation, major corporate results — the normal market microstructure signals become unreliable. Smart money already knows the outcome or is positioning for it. The agent must be told the macro backdrop before it interprets any OI or delta data.

# agent/news_bias.py — translates macro context to agent instructions

def get_bias_instruction(macro_context):
    instructions = []

    if macro_context["rbi_event_today"]:
        instructions.append(
            "RBI event day. Do NOT trade before the announcement. "
            "After announcement: trade only WITH the announced direction, "
            "confluence ≥ 8 required. Max Pain is irrelevant today."
        )

    if macro_context["global_sentiment"] == "RISK_OFF":
        instructions.append(
            "Global risk-off environment. Bearish bias. "
            "Be more aggressive on SELL setups, more cautious on BUY setups. "
            "Require extra delta confirmation for bullish entries."
        )

    sgx_gap = float(macro_context["sgx_nifty_gap"].replace('%',''))
    if abs(sgx_gap) > 0.5:
        direction = "gap-up" if sgx_gap > 0 else "gap-down"
        instructions.append(
            f"SGX shows {direction} of {abs(sgx_gap):.1f}%. "
            "Expect opening momentum in gap direction for 15–20 mins, "
            "then high probability of gap fill. Do not trade first 15 minutes. "
            "Watch for stop-hunt above/below opening gap level."
        )

    if macro_context["earnings_today"]:
        stocks = ", ".join(macro_context["earnings_today"])
        instructions.append(
            f"Results today: {stocks}. Watch for index-level impact. "
            "Large beats/misses can override normal OI signals."
        )

    return " | ".join(instructions) if instructions else "No major macro events. Trade setups normally."

4 — Option Selection Logic
STEP 1 — Direction from agent decision BUY index signal → buy Call (CE) SELL index signal → buy Put (PE) STEP 2 — Calculate ATM strike NIFTY: round(LTP / 50) × 50 SENSEX: round(LTP / 100) × 100 STEP 3 — Select OTM depth based on budget SENSEX (lot 20): If confidence ≥ 8 and time < 11:00 AM → ATM (if premium × 20 ≤ ₹2,000) If confidence 6–7 or time 11:00–13:30 → 1-OTM If time > 13:30 → 2-OTM only (low cost, big gamma potential) NIFTY (lot 75): ONLY trade if premium ≤ ₹26 (cost ≤ ₹1,950) Always 2–3 strikes OTM (never ATM — too expensive) Confidence must be ≥ 8 to trade NIFTY at all with this budget STEP 4 — OI wall check If target strike has highest Call OI (for CE) → move 1 strike further OTM If target strike has highest Put OI (for PE) → move 1 strike further OTM Market makers defend high-OI strikes — don't buy exactly where they park STEP 5 — Final budget gate cost = premium × lot_size if cost > 2000: reject, try next OTM strike if cost < 400: too far OTM, delta too low — WAIT instead if 400 ≤ cost ≤ 2000: proceed to entry logic
5 — Entry Logic
1
Agent issues structured decision with entry zone
e.g. "Enter SENSEX 81500 PE if SENSEX trades at or below 81400 on next 1m close. Invalidated if SENSEX closes above 81700."
2
Entry watcher monitors index LTP each tick
Entry fires when: (a) index price enters zone AND (b) the 1m candle closes in zone — not just wicks through it. Wick entries are traps.
3
Delta confirmation check
At the moment of entry trigger, verify: last 2 candles of order flow delta still agree with direction. If delta has reversed, abort entry — setup has changed since agent call.
4
Place limit order at ask price
Never market orders on options — expiry day spreads are wide. Place at the current ask. If not filled in 30 seconds, cancel and re-evaluate. If refilled at ask+1 tick, accept once.
5
Entry window: 10 minutes max
If entry condition is not met within 10 minutes of the agent call, discard the setup. Price has moved on. The agent gets a "setup expired" notification and resets to watch mode.
6 — Take Profit & Exit Rules
Core Philosophy — Expiry Options Decay Fast, Profits Must Be Taken
On expiry day a winning option that you hold too long becomes a loser. Theta collapses are non-linear — the last 90 minutes see the steepest decay. Take partial profit aggressively, trail the rest.
Exit Rule	Trigger	Action
TP1	Premium up 50% from entry	Exit 50% of position. Move stop to breakeven on remainder.
TP2	Premium up 100% (doubled)	Exit another 30%. Remaining 20% runs with trailing stop.
TP3 — Trail	After TP2, premium starts falling	Trail stop = 30% below highest premium seen. Exit when breached.
Stop Loss	Premium falls 50% from entry	Exit 100% immediately at market. No waiting. No hoping.
Invalidation	Index crosses agent's stated invalidation level	Exit 100% regardless of premium. The trade thesis is broken.
No New Entries	After 2:15 PM	System blocks all new entry orders. Only exits allowed.
Hard Close	3:00 PM sharp	Close ALL positions at market. No exceptions. Session ends.
# execution/position_monitor.py — core exit logic

def monitor_position(position, market_state):
    current_premium = market_state.option_ltp(position.instrument)
    pnl_pct = (current_premium - position.entry_premium) / position.entry_premium * 100
    now = market_state.time

    # Time rules
    if now >= time(15, 0):
        return Action.EXIT_FULL("Hard close 3:00 PM")

    if now >= time(14, 15) and not position.has_open_qty:
        return Action.BLOCK_NEW_ENTRY

    # Invalidation
    if position.direction == "BUY" and market_state.index_ltp > position.invalidation:
        return Action.EXIT_FULL("Invalidation breached — thesis broken")
    if position.direction == "SELL" and market_state.index_ltp < position.invalidation:
        return Action.EXIT_FULL("Invalidation breached — thesis broken")

    # Stop loss
    if pnl_pct <= -50:
        return Action.EXIT_FULL("Stop loss — 50% premium lost")

    # TP1
    if pnl_pct >= 50 and not position.tp1_hit:
        position.tp1_hit = True
        position.stop = position.entry_premium  # Move to breakeven
        return Action.EXIT_PARTIAL(0.5, "TP1 — 50% profit, half out")

    # TP2
    if pnl_pct >= 100 and position.tp1_hit and not position.tp2_hit:
        position.tp2_hit = True
        position.trail_high = current_premium
        return Action.EXIT_PARTIAL(0.3, "TP2 — 100% profit, 30% more out")

    # Trail stop on remaining
    if position.tp2_hit:
        if current_premium > position.trail_high:
            position.trail_high = current_premium
        trail_stop = position.trail_high * 0.70
        if current_premium <= trail_stop:
            return Action.EXIT_FULL("Trail stop triggered")

    return Action.HOLD
7 — Technology Stack
Runtime
Python 3.11+ / asyncio
Single async event loop handles WebSocket ticks, candle building, analysis, and order management without threads. No blocking I/O on the hot path.
Broker / Data
Upstox v2 API
WebSocket for live ticks (index + options). REST for init, option chain, order placement, order status. Official Python SDK available.
Indicators
pandas-ta
EMA, VWAP, RSI, MACD, Bollinger Bands, ATR all in one library. Computed on candle close, not every tick. Clean pandas integration.
AI Agent
Anthropic API (claude-opus-4 / claude-sonnet-4-5)
claude-sonnet-4-5 for speed and cost on most calls. Reserve claude-opus-4 for high-conviction scenarios only. JSON mode for structured output.
Current Affairs
NewsAPI + yfinance + investpy
NewsAPI for headlines (free tier). yfinance for crude, USD/INR, SGX Nifty proxy. Pre-market scan runs once at 8:30 AM, refresh at 12:00 PM.
Dashboard
Rich (terminal UI)
Live terminal dashboard with tables, live P&L, current position, agent calls log. No web server needed. Runs in the same terminal as the main process.
State Storage
In-memory Python dicts
No database on the hot path. Candles, ticks, state all in memory. SQLite used only for end-of-day trade log persistence and historical IV data.
Scheduling
APScheduler
Handles pre-market scan at 8:30 AM, hard close at 3:00 PM, and daily log write at 3:05 PM. Integrates cleanly with asyncio event loop.

11 — Hard Risk Rules (System-Enforced)
These are enforced in code — not guidelines
Max per trade: ₹2,000. option_selector.py rejects any instrument where premium × lot_size > 2000.
NIFTY only if premium ≤ ₹26 (cost ≤ ₹1,950 for lot 75). Always rejected if above this.
Max 2 open positions. order_manager.py blocks new entries if 2 positions open.
Stop loss: 50% of premium. position_monitor.py exits at market — no override.
No new entries after 2:15 PM. entry_watcher.py checks time before firing.
Hard close at 3:00 PM. APScheduler fires — all positions closed at market, no exceptions.
Daily loss limit: ₹1,500. If day's P&L hits -₹1,500, system shuts off all new entries for the session.
No trades on non-expiry days. main.py checks: is today Tuesday (SENSEX) or Thursday (NIFTY)? If no, agent never runs.
No trades during HIGH IMPACT macro events until event resolves. news_bias.py sets a trading_blocked flag that entry_watcher respects.
